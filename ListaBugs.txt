## Bugs Historicos Ya Corregidos

Estos puntos aparecian en la lista previa, pero el codigo actual ya no coincide con esa descripcion:

- IPC ya se registra dentro de `app.whenReady()` en `electron/main.ts`.
- El cierre durante operaciones ya usa un flag `forceClose`.
- El boton para instalar Winget ya usa `system:open-url`.
- El preload ya conserva el wrapper de listeners para poder removerlos con `off()`.
- `HistoryItem` ya esta importado en `src/renderer.d.ts`.
- El logger ya escribe en `app.getPath('userData')`.
- `SystemService` ya se instancia una sola vez y se comparte con `WingetService`.
- La creacion de restore point usa comillas simples y escape basico para la descripcion.
- El estado visual de Select All ya compara contra updates seleccionables, no contra todos los updates.
- El typo principal de `scanningBody` en espanol ya esta corregido.
- El flujo de batch limpia la marca de operacion activa en `finally`.

## Correcciones Aplicadas En Esta Pasada

### 1. Descarga de update de la app

Estado: Corregido
Archivos:

- `src/main/services/app-update.ts`
- `src/main/ipc.ts`

Cambio:

- El nombre de archivo recibido para `system:download-app-update` ahora se valida en main process.
- Se rechazan nombres vacios, rutas, separadores, caracteres invalidos, nombres demasiado largos y extensiones fuera de `.zip`/`.exe`.

### 2. Estado global de operacion activa

Estado: Corregido
Archivos:

- `electron/main.ts`
- `electron/preload.ts`
- `src/renderer.d.ts`
- `src/hooks/useUpdateFlow.ts`

Cambio:

- Se reemplazo el boolean libre `system:set-operation-active` por un flujo con token:
  - `system:begin-operation`
  - `system:end-operation`
- El main process solo permite finalizar la operacion activa con el token correcto.

### 3. Validacion de historial

Estado: Corregido
Archivos:

- `src/main/ipc.ts`
- `src/main/services/history.ts`

Cambio:

- `history:add` valida payload antes de persistir.
- Se validan strings requeridos, strings opcionales y estados permitidos.
- El schema de historial incluye `previousVersion`.

### 4. Validacion de ignores temporales

Estado: Corregido
Archivos:

- `src/main/ipc.ts`
- `src/main/services/ignore.ts`

Cambio:

- `ignore:add-temporary` valida formato y longitud de package id.
- `availableVersion` se normaliza y limita antes de persistir.

### 5. Backups de settings e historial

Estado: Corregido
Archivos:

- `src/main/services/settings.ts`
- `src/main/services/history.ts`

Cambio:

- El archivo `.bak.json` ahora se crea antes de escribir el nuevo estado, por lo que conserva el estado anterior.

### 6. Limpieza de residuos de template/debug

Estado: Corregido
Archivos:

- `index.html`
- `electron/preload.ts`
- `src/App.css`

Cambio:

- El favicon apunta a `logo.png`.
- El titulo HTML es `All Updater`.
- Se eliminaron logs de depuracion del preload.
- Se elimino `src/App.css`, archivo remanente no importado.
